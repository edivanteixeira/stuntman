# Security policy

Stuntman is a test tool with **no sign-in yet**. Run it only on your machine, in CI, or on a private network behind
something that authenticates. Details: [docs/security.md](docs/security.md).

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting: **Security › Report a vulnerability**
on this repository. You will get an answer within a few days.
